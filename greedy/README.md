# 贪心算法详解

---

## 一、什么是贪心算法

### 1.1 核心思想

**贪心算法**（Greedy Algorithm）在每一步选择中都采取当前状态下的最优选择，期望通过局部最优解得到全局最优解。

```
贪心 ≠ 永远正确
贪心 ≠ 局部最优 = 全局最优（需要证明）
```

### 1.2 贪心 vs 动态规划

| 维度 | 贪心 | 动态规划 |
|------|------|----------|
| 选择方式 | 局部最优，不回溯 | 全局最优，可能回溯 |
| 时间复杂度 | 通常 O(n) 或 O(nlogn) | 通常 O(n²) 或 O(nlogn) |
| 最优性 | 不一定正确，需证明 | 一定正确 |
| 适用场景 | 问题具有贪心选择性质 | 问题具有最优子结构 |

---

## 二、如何判断是否适用贪心

### 2.1 贪心选择性质

**定义**：每一步的最优解可以由局部最优推导全局最优。

### 2.2 判断技巧

| 问题特征 | 是否适用贪心 |
|----------|-------------|
| 排序后贪心选择 | ✅ 通常适用 |
| 每次选最大/最小 | ✅ 可能适用 |
| 区间问题（按端点排序） | ✅ 适用 |
| 无后效性（选择不影响未来） | ✅ 适用 |
| 需要回溯才能确定最优 | ❌ 不适用 |
| 排列组合最优解 | ❌ 通常用 DP |

## 四、区间调度问题

### 4.1 最多不重叠区间

#### 题目特征

```
给多个区间，问最多能选几个不重叠的？
```

#### 解法模板

```go
// 按结束时间排序，依次选择
func maxNonOverlap(intervals [][]int) int {
    if len(intervals) == 0 {
        return 0
    }
    // 按结束时间升序
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][1] < intervals[j][1]
    })

    count := 1
    end := intervals[0][1]
    for i := 1; i < len(intervals); i++ {
        if intervals[i][0] >= end {
            count++
            end = intervals[i][1]
        }
    }
    return count
}
```

### 4.2 合并重叠区间

#### 解法模板

```go
func merge(intervals [][]int) [][]int {
    if len(intervals) == 0 {
        return intervals
    }
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][0] < intervals[j][0]
    })

    result := [][]int{intervals[0]}
    for i := 1; i < len(intervals); i++ {
        if intervals[i][0] <= result[len(result)-1][1] {
            // 合并
            result[len(result)-1][1] = max(result[len(result)-1][1], intervals[i][1])
        } else {
            result = append(result, intervals[i])
        }
    }
    return result
}
```

## 五、跳跃游戏问题

### 5.1 能否到达（p55）

#### 解法模板

```go
func canJump(nums []int) bool {
    farthest := 0
    for i := 0; i < len(nums); i++ {
        if i > farthest {
            return false
        }
        farthest = max(farthest, i+nums[i])
    }
    return true
}
```

### 5.2 最少跳跃次数（p45）

#### 解法模板

```go
func jump(nums []int) int {
    if len(nums) <= 1 {
        return 0
    }
    jumps := 0
    cur := 0      // 当前覆盖范围
    next := 0     // 下一步覆盖范围

    for i := 0; i < len(nums)-1; i++ {
        next = max(next, i+nums[i])
        if i == cur {
            jumps++
            cur = next
        }
    }
    return jumps
}
```

func findContentChildren(g []int, s []int) int {
    sort.Ints(g)
    sort.Ints(s)
    gi, si := 0, 0
    for gi < len(g) && si < len(s) {

## 八、柠檬水找零

### 8.1 解法模板

```go
func lemonadeChange(bills []int) bool {
    five, ten := 0, 0
    for _, bill := range bills {
        if bill == 5 {
            five++
        } else if bill == 10 {
            if five > 0 {
                five--
                ten++
            } else {
                return false
            }
        } else { // bill == 20
            if ten > 0 && five > 0 {
                ten--
                five--
            } else if five >= 3 {
                five -= 3
            } else {
                return false
            }
        }
    }
    return true
}
```

## 十、贪心算法思维流程

```
开始
  │
  ├─ 问题是否需要排序？
  │    ├─ 是 → 继续
  │    └─ 否 → 检查其他特征
  │
  ├─ 按结束时间排序？
  │    ├─ 最多不重叠 → 选择最早结束的
  │    └─ 合并重叠 → 合并区间
  │
  ├─ 按起始排序？
  │    └─ 合并重叠区间
  │
  ├─ 跳跃问题？
  │    ├─ 能否到达 → 维护最远距离
  │    └─ 最少次数 → 双指针/贪心
  │
  └─ 双指针匹配？
       └─ 分发饼干、找零 → 贪心匹配
```

## 十一、面试高频问题

### Q1: 贪心算法的正确性如何证明？

**数学归纳法**：
1. 证明第一步选择最优
2. 假设前 k 步最优
3. 证明第 k+1 步也最优

### Q2: 贪心和 DP 如何选择？

| 问题 | 选择 |
|------|------|
| 有最优子结构 + 重叠子问题 | DP |
| 局部最优能推导全局最优 | 贪心 |
| 需要考虑所有情况 | 回溯/DP |

### Q3: 什么时候用贪心？

- 问题具有**贪心选择性质**
- 每步选择不影响未来选择（**无后效性**）
- 问题可证能用贪心

### Q4: 贪心失败怎么办？

贪心失效时，考虑使用：
- 动态规划
- 回溯算法

## 十三、贪心算法要点总结

### 核心要点

1. **排序是贪心的灵魂**：大多数贪心问题需要排序
2. **证明是关键**：不是所有问题都能用贪心
3. **局部最优 ≠ 全局最优**：需要数学证明
4. **排序依据决定策略**：按结束时间 vs 起始时间
5. **双指针配合贪心**：常用于区间问题

### 贪心解题套路

```
1. 排序（通常按结束时间/起始时间）
2. 选择当前最优
3. 验证（模拟走一遍）
4. 边界处理（空数组、单个元素）
```
